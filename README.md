# OOCSI + ESP32 Project

An ESP32 connected to a magnet sensor. In the object (vinyl in our case) there will be the magnet to trigger the sensor. 
Once the ESP32 gets a signal the sensor is triggered the color in accordance with the state will be triggered.

## Hardware

- Sensors/actuators used:
- Reed switches
- Magnets
- Wires
- Breadboard

## Digital component
0 -> black
1 -> red
2 -> green
3 -> blue
4 -> disco
